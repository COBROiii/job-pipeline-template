# Outreach contacts

One row per person. You send every message yourself; Claude drafts and keeps this table current.
Statuses: `drafted` → `sent` (connection request or email sent) → `accepted` → `replied` → `call booked` → `call done` → `referral asked` → `referred`. Side exits: `no reply` (after one follow-up), `declined`, `skip`.
Tier: `network` (people you know) → `fits-bill` (already doing the role: alumni, recent grads) → `engineer` / `recruiter` (about 2:1). Lets you compare reply rates by tier.
Channel: `LinkedIn` or `email (listed)` / `email (pattern from <site>)` / `email (guessed, unverified)`.
Drafts live in `applications/jobs/<id>/outreach.md`.
