# Application tracker

Statuses: `found` → `scouted` → `drafted` → `ready` (you approved the answers) → `applied`. Side exits: `skipped`, `blocked` (needs you: sign-in, CAPTCHA, missing CV, CHECK items).

- **Fit**: the job-seeker's first guess (A/B/C), replaced by the evaluator's score, e.g. `81 A`.
- **Answers**: the evaluator's answer score and verdict, e.g. `84 submit`, `68 revise`, `40 skip`.

Completed applications: 0 via /apply or /apply-lite
Answer-bank coverage (tagged answers): motivation 0 · why-company 0 · teamwork 0 · technical-project 0 · failure 0. At 2+ each, /apply-lite is ready.

Job ID format: `company-role` in lowercase with hyphens, e.g. `acme-graduate-engineer`.
